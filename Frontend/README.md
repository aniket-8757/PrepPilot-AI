# PrepPilot AI

PrepPilot AI is an AI-powered interview preparation platform that helps candidates prepare for job interviews with tailored role analysis, technical and behavioral question practice, and personalized roadmaps.

## Features

- Upload a resume or describe your profile
- Paste a job description for role-specific analysis
- Generate interview questions and answers
- Get match score and skill-gap insights
- Download a polished resume version

## Frontend

This frontend is built with React and Vite.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

# PrepPilot AI

PrepPilot AI is an AI-powered interview preparation platform that generates personalized interview plans based on job descriptions and helps candidates prepare for job-specific interviews.

## Features

- AI-powered interview preparation
- Personalized interview plans
- Job-description-based preparation
- Technical and behavioral interview practice
- User-friendly web interface

## Tech Stack

- Frontend: React.js
- Backend: Node.js
- AI: Generative AI
- Git & GitHub
